# مكتبة د. نادر عبدالرحمن المطيري

موقع ثابت لنشر كتابين توعويين في طب الأطفال.

## خطوات النشر
1. أنشئ مستودع GitHub **عامًا Public** بالاسم الدقيق `nader-pediatric-books` من الحساب `Mosabalrezeni`.
2. ارفع **كل محتويات هذا المجلد** إلى جذر المستودع (لا ترفع ملف ZIP وحده).
3. افتح Settings → Pages → Build and deployment، واختر Deploy from a branch، ثم `main` و`/(root)` واضغط Save.
4. بعد نجاح النشر تأكد من فتح: https://mosabalrezeni.github.io/nader-pediatric-books/
5. جرّب مسح رمزي QR على هاتف آخر قبل طباعتهما.

مهم: الأكواد مبنية على اسم المستودع المحدد أعلاه. أي تغيير في اسم المستودع أو اسم الحساب يستلزم إنشاء QR جديد. المحتوى المنشور سيكون عامًا، بما في ذلك ملفات PDF.
